## 🧬 RNA modification pipelines

Single-base-resolution detection of RNA epitranscriptomic modifications — from method to pipeline.

| Pipeline | What it does | |
|:---|:---|:-:|
| [**m5C-UBSseq**](https://github.com/y9c/m5C-UBSseq) | Ultrafast bisulfite sequencing pipeline for m⁵C detection | [![stars](https://img.shields.io/github/stars/y9c/m5C-UBSseq?style=flat-square&color=yellow)](https://github.com/y9c/m5C-UBSseq) |
| [**pseudoU-BIDseq**](https://github.com/y9c/pseudoU-BIDseq) | Pipeline for detecting Ψ (pseudouridine) modification at single-base resolution | [![stars](https://img.shields.io/github/stars/y9c/pseudoU-BIDseq?style=flat-square&color=yellow)](https://github.com/y9c/pseudoU-BIDseq) |
| [**m6A-SACseq**](https://github.com/y9c/m6A-SACseq) | Optimized protocol & pipeline for m⁶A-SAC-seq | [![stars](https://img.shields.io/github/stars/y9c/m6A-SACseq?style=flat-square&color=yellow)](https://github.com/y9c/m6A-SACseq) |
| [**m6A-CAMseq**](https://github.com/y9c/m6A-CAMseq) | Pipeline for m⁶A-CAM-seq | [![stars](https://img.shields.io/github/stars/y9c/m6A-CAMseq?style=flat-square&color=yellow)](https://github.com/y9c/m6A-CAMseq) |
| [**trichromat**](https://github.com/y9c/trichromat) | General pipeline for 3-letter conversion sequencing methods | [![stars](https://img.shields.io/github/stars/y9c/trichromat?style=flat-square&color=yellow)](https://github.com/y9c/trichromat) |
| [**m6A-eTAMseq**](https://github.com/y9c/m6A-eTAMseq) | Enzymatic method for assaying m⁶A at single-base resolution | [![stars](https://img.shields.io/github/stars/y9c/m6A-eTAMseq?style=flat-square&color=yellow)](https://github.com/y9c/m6A-eTAMseq) |
| [**pseudoU-PUMseq**](https://github.com/y9c/pseudoU-PUMseq) | Ψ-PUMseq pipeline for pseudouridine detection | [![stars](https://img.shields.io/github/stars/y9c/pseudoU-PUMseq?style=flat-square&color=yellow)](https://github.com/y9c/pseudoU-PUMseq) |
| [**dichromat**](https://github.com/y9c/dichromat) | Containerized pipeline for conversion sequencing (eTAM-seq, CAM-seq, GLORI, BS-seq): mapping → site-calling → reporting | [![stars](https://img.shields.io/github/stars/y9c/dichromat?style=flat-square&color=yellow)](https://github.com/y9c/dichromat) [![new](https://img.shields.io/badge/new-2026-2ea44f?style=flat-square)](https://github.com/y9c/dichromat) |
